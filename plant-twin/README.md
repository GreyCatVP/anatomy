# Цифровой двойник цеха ЭПК

3D-модель и модель процесса цеха эпоксидных порошковых красок для наружной изоляции труб (CSA Z245.20, ISO 21809).

Цех: склад сырья, буфер приёмки, дозировка с весоучётом, 3 смесителя CMR-1000, 4 линии (TSE-70C → охлаждающие валки → CCB-1000 → дробилка → ACM-50 + APW-30A), 4 системы тонкого помола с циклонами, рукавными фильтрами и вентиляторами, автоматическая фасовка с точностью 0,001 кг, карантин до ОТК, склад продукции с доками, лаборатория ОТК и R&D, инженерные системы.

## Запуск

Готовая страница лежит в `dist/index.html`. Откройте её в браузере. Нужен интернет: three.js и шрифты грузятся с CDN.

Сборка из исходников:

```
npm install
npm run build      # dist/index.html и dist/artifact.html
npm run dev        # локальный сервер на http://localhost:8080 для работы с src/
```

## Что умеет

- Вращение, сдвиг, масштаб к курсору, перелёт к станку двойным кликом или из реестра.
- Режимы: «Модель» (белая макетная модель с контурами), «Рентген», «Статус», «Загрузка».
- Слои: стены (ближняя к камере гаснет сама), кровля с фермами, инженерные сети, люди, подписи, разметка.
- Симуляция: заказы, партии премикса, 12 контейнеров и 2 погрузчика, цикл смесителя с поворотом на 180°, прогрев и переналадка линий, фасовка с переключением бункеров, паллетирование, лоты и испытания ОТК, отгрузка по расписанию, календарь смен.
- Инспектор: показания модели, история за 4 часа, паспорт, остановка и пуск станка в двойнике.
- Вкладка «Мощность и загрузка»: пропускная способность участков, узкое место, выпуск в месяц по режимам смен.

## Данные и допущения

Все цифры считает модель процесса. Производительности, циклы и время испытаний типовые, это допущения, а не паспортные данные. Их можно менять во вкладке «Мощность и загрузка» или в `src/sim/model.js` (`DEFAULTS`). Назначение APW-30A по маркировке не определено, геометрия условная.

В реестре (`src/plant/layout.js`) каждая единица помечена по происхождению:

- из исходной схемы цеха;
- добавлена как технологически необходимая (питатели, валки, дробилки, фильтры, вентиляторы, конвейер коробов, паллетайзер и т. д.);
- добавлена как требование стандарта (установка катодного отслаивания, стенд испытаний на изгиб).

## Структура

```
src/core/      геометрический кит (слияние деталей в меши, контуры рёбер), материалы
src/eq/        станки и узлы: process, milling, prep, packing, lab, utilities, actors
src/scene/     здание: каркас, ограждение, кровля, разметка, оси
src/plant/     реестр и расстановка, инженерные сети, привязка модели к 3D
src/sim/       модель процесса, телеметрия, расчёт мощности
src/view/      рендер, камера, пикинг, подписи, режимы
src/ui/        интерфейс
```
